Welcome, Developer

This guide covers everything you need to start contributing to the WhoIsDésir® Media platform. Whether you're a vibe coding specialist, front-end developer, or full-stack contributor — this is your home base.

1. Getting Access

1
GitHub Access: Your agency admin will invite you to the whoisdesirtech/widmediaagency repository. Accept the invite via email.
2
Vercel Access: Ask your admin to add you to the Vercel team for deploy previews and production access.
3
Supabase Access: Request read-only access to the Supabase dashboard for database inspection.

2. Local Setup

# Clone the repo
git clone https://github.com/whoisdesirtech/widmediaagency.git
cd widmediaagency

# Install dependencies
npm install

# Copy environment variables
cp .env.example .env
# Fill in DATABASE_URL, NEXTAUTH_SECRET, etc.

# Apply database schema
npm run db:push

# Seed dev data (optional)
npm run db:seed

# Start dev server
npm run dev

The dev server runs at http://localhost:3000

4. Auth Pattern (IMPORTANT)

Every API route must start with an auth guard:

import { requireAdmin, requireAuth, isNextResponse } from '@/lib/auth';

// Admin-only route
const user = await requireAdmin();
if (isNextResponse(user)) return user;

// Any authenticated role
const user = await requireAuth(['admin', 'staff', 'contractor']);
if (isNextResponse(user)) return user;
Never skip the guard. Every new route handler must include an auth check as its first line.

5. Git Workflow

1
Never commit to main. Always create a feature branch: git checkout -b feat/your-feature
2
Conventional commits: Use feat:, fix:, chore:, docs: prefixes.
3
Typecheck before committing: npm run typecheck must pass clean.
4
Open a PR: Push your branch and open a pull request to main. Wait for review/merge.

6. Key Conventions

  • Stack: Next.js 14 App Router, TypeScript, Tailwind CSS, Prisma + PostgreSQL
  • Styling: Use Tailwind utility classes. Custom tokens: miami-pink, miami-blue-light, dark-800, muted
  • Components: Check src/components/ before creating new ones
  • File uploads: Whitelist file types and sizes per route (10MB docs, 15MB images, 100MB Drive)
  • ESLint: Not configured — do not run next lint
  • Verify: Always run npm run typecheck before pushing

7. Vibe Coding Guidelines

If you're using AI-assisted development (Cursor, Copilot, Bolt, Lovable, etc.):

  • Always review generated code — AI can produce incorrect auth patterns or skip guards
  • Run typecheck after every AI-generated change — npm run typecheck
  • Don't blindly accept AI suggestions for security-sensitive code (auth, API routes, file uploads)
  • Check existing patterns first — look at neighboring files before generating new code
  • Test locally — npm run dev and verify the feature works before committing
Pro tip: When prompting AI, include context: "This is a Next.js 14 App Router project using Prisma + PostgreSQL. Follow the existing auth pattern in src/lib/auth.ts."

8. Common Tasks

Add a new API route

// src/app/api/your-route/route.ts
import { NextResponse } from 'next/server';
import { requireAdmin, isNextResponse } from '@/lib/auth';

export async function GET(req: Request) {
  const user = await requireAdmin();
  if (isNextResponse(user)) return user;
  // Your logic here
  return NextResponse.json({ data: 'hello' });
}

Add a new page

// src/app/your-page/page.tsx
export default function YourPage() {
  return <div>Hello World</div>;
}

Create a database migration

# Edit prisma/schema.prisma, then:
npm run db:push

Deploy to production

# Push to main (via PR merge) or:
vercel --prod --yes
