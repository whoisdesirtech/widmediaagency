Getting Started
Essential lessons for everyone — vendors, clients, and admins
1
How to Log In
Everyone ▾

Every user — vendor, client, or admin — logs in through the same portal.

1
Open the login page: https://whoisdesirmediaagency.vercel.app/login
2
Enter your email and password. These were provided to you by your agency admin.
3
Click "Sign In." You'll be automatically redirected to your portal based on your role.
Tip: Bookmark the login page for quick access. You can log in from any device.
2
Forgot Your Password?
Everyone ▾
1
Go to the login page and click "Forgot password?"
2
Enter your email address and click "Reset Password."
3
Check your email for a reset link. Follow the instructions to set a new password.
Still can't log in? Contact your agency admin directly — they can reset your password manually.
3
Understanding Your Dashboard
Everyone ▾

After logging in, you land on your Dashboard. This is your home base.

Use the sidebar on the left to navigate to different sections.

Developer Lessons
For vibe coding specialists and front-end developers contributing to the platform
D1
Getting Started as a Developer
Developer ▾

Developers are onboarded as contractors with the developer role. Once assigned, you get access to the Developer Workspace in your portal.

1
Get GitHub access: Your admin invites you to the whoisdesirtech/widmediaagency repository.
2
Get Vercel access: Your admin adds you to the Vercel team for deploy previews.
3
Clone & set up: Clone the repo, install deps, copy .env.example to .env, run npm run db:push and npm run dev.
4
Open Developer Workspace: Click "Developer Workspace" in your sidebar for quick links and setup reference.
D2
Git Workflow & Branching
Developer ▾
1
Never commit to main. Always create a feature branch: git checkout -b feat/your-feature-name
2
Conventional commits: Use prefixes — feat:, fix:, chore:, docs:, refactor:
3
Typecheck before pushing: Run npm run typecheck — it must pass clean.
4
Open a PR: Push your branch and create a pull request to main. Wait for review.
AGENTS.md rule: Never commit directly to main. Always use feature branches + PRs.
D3
Auth & API Route Patterns
Developer ▾

Every API route must start with an auth guard. Never skip this.

Admin-only route:

const user = await requireAdmin(); if (isNextResponse(user)) return user;

Any authenticated role:

const user = await requireAuth(['admin', 'staff', 'contractor']); if (isNextResponse(user)) return user;

Helpers are in src/lib/auth.ts. Roles: admin, staff, contractor, client.

D4
Vibe Coding Best Practices
Developer ▾

When using AI-assisted development (Cursor, Copilot, Bolt, Lovable, etc.):

  • Review all generated code — AI can skip auth guards or produce incorrect patterns
  • Run typecheck after every change — npm run typecheck
  • Check existing patterns first — look at neighboring files before generating new code
  • Include context in prompts: "Next.js 14 App Router, Prisma + PostgreSQL, follow auth pattern in src/lib/auth.ts"
  • Test locally — npm run dev and verify before committing
D5
Tech Stack Reference
Developer ▾
  • Framework: Next.js 14 App Router
  • Language: TypeScript (strict-ish)
  • Styling: Tailwind CSS with custom tokens (miami-pink, miami-blue-light, dark-800, muted)
  • Database: PostgreSQL via Supabase, Prisma ORM (16 models)
  • Auth: NextAuth.js credentials strategy
  • File storage: Google Drive API via service account
  • Deploy: Vercel
  • Commands: npm run dev, npm run typecheck, npm run db:push, npm run db:seed
Full docs: Visit /developer on the live site for API reference, architecture diagrams, and database schema details.

Google Drive Integration
How vendors upload and clients access files via Google Drive
14
How Google Drive Integration Works
Everyone ▾

The platform uses a Google Service Account to upload and read files from Google Drive. Here's how each role interacts with it:

  • Admins create a Shared Drive, create client folders, share them with the service account, and link the folder ID to the client record
  • Vendors select a client's folder from a dropdown on the project page and upload photos/videos directly to Google Drive
  • Clients browse their Media Gallery to view files, or click "Open in Google Drive" to download
Important: Client folders MUST be in a Shared Drive (not "My Drive"). Service accounts cannot upload to personal Drive folders — you'll get a storage quota error.
14a
Admin: Setting Up Google Drive for a Client
Admin ▾

Follow these steps to enable Google Drive delivery for a client. This must be done before vendors can upload files.

1
Create a Shared Drive in Google Drive (if you haven't already). Name it something like "WhoIsDesir Media — Client Files". Shared Drives are required — personal "My Drive" folders won't work.
2
Create a folder for the client inside the Shared Drive. Name it after the client or project (e.g., "Start Social — World Cup"). Optionally create sub-folders like "Photography", "Video", "Final Deliverables".
3
Share the folder with the service account: Right-click the folder → Share → add widmedia-drive-upload@whoisdesir-media.iam.gserviceaccount.com → set to Editor → Send.
4
Copy the Folder ID from the URL. Open the folder → the URL is https://drive.google.com/drive/folders/FOLDER_ID_HERE. Copy the ID portion.
5
Link it in the admin portal: Go to Clients → click the client → Edit Client → scroll to "Google Drive Media Folder" → paste the Folder ID and the full URL → Save.
6
Verify: The client's Overview card should now show "✓ Linked" for Media Folder. Vendors can now upload to this client's Drive.
For multiple folders (Photography, Video, etc.): Go to the client's "Folders" or "Media Gallery" tab → create named folders with their own Drive folder IDs. Vendors can then pick the specific sub-folder when uploading.
15
Vendor: Uploading Photos & Videos to Client's Google Drive
Vendor ▾

Once your agency admin has linked a Google Drive folder to the client, you can upload deliverables directly from the platform.

1
Go to Projects in your sidebar → click into the project you're working on.
2
Select the Drive folder: Use the dropdown to pick which client folder to upload to (e.g., "Photography", "Video").
3
Upload files: Click the upload button and select your photos or videos. Accepted: JPG, JPEG, PNG, WEBP, GIF (images), MP4, MOV, AVI (videos). Max 15MB per image, 100MB per file.
4
Files go directly to Google Drive — the client can see them in their Media Gallery immediately.
Don't see the folder dropdown? Your admin hasn't linked a Google Drive folder to this client yet. Ask them to set it up (see the admin setup lesson above).
16
Client: Accessing & Downloading Files from Google Drive
Client ▾

When vendors upload files to your Google Drive, you can access them through your Media Gallery.

1
Log in to the client portal → click "Media Gallery" in the sidebar.
2
Browse folders: You'll see the folders your admin created (e.g., "Photography", "Video"). Click a folder to open it.
3
View files: Images and files are displayed in an embedded Google Drive view. Click any file to preview it.
4
Download files: Click the "Open in Google Drive" button to open the folder directly in Google Drive, where you can download individual files or entire folders.
Empty gallery? Your admin may not have linked a Google Drive folder yet. Ask them to set it up. Once linked, any files vendors upload will appear here automatically.
17
Troubleshooting Google Drive Issues
Everyone ▾

If you encounter issues with Google Drive uploads or access:

  • "Service Accounts do not have storage quota" — The folder is in someone's "My Drive", not a Shared Drive. Ask your admin to move it to a Shared Drive.
  • 403 / Permission denied — The service account hasn't been shared on the folder. Ask your admin to add widmedia-drive-upload@whoisdesir-media.iam.gserviceaccount.com as Editor.
  • 503 error — Google Drive API is temporarily unavailable. Wait a few minutes and try again.
  • "Drive not configured" — The Google Drive credentials aren't set in the platform. Ask your admin to check the Vercel environment variables.
  • Folder dropdown doesn't appear — No Google Drive folders are linked to this client. Ask your admin to link one.
  • Client gallery is empty — Either no files have been uploaded yet, or the Folder ID is wrong. Ask your admin to verify the setup.

Frequently Asked Questions
Common questions and quick answers
18
I can't log in — what should I do?
Everyone ▾
  1. Use the "Forgot password?" link on the login page
  2. Check your email (including spam/junk folder)
  3. If that doesn't work, contact your agency admin — they can reset your password manually
19
My file upload failed — what do I do?
Everyone ▾
  • Check file size: Onboarding docs max 10MB, project images max 15MB, Drive uploads max 100MB
  • Check file type: Onboarding accepts PDF, JPG, PNG. Project images accept JPG, JPEG, PNG, WEBP, GIF. Drive accepts most common formats.
  • Check your connection: Try again with a stable internet connection
  • Google Drive errors: See the Google Drive troubleshooting lesson above
20
How do I get a copy of my signed contract?
Everyone ▾

Go to "My Contracts" (vendors) or "Documents" (clients) → select the contract → click "Download" to save an HTML copy.

21
Who do I contact for help?
Everyone ▾
  • Login issues: Your agency admin can reset your password
  • Contract questions: Ask your agency admin before signing
  • Google Drive issues: Ask your agency admin to verify the setup
  • Technical issues: Contact your agency support team directly
  • Billing questions: Reach out to your agency's finance contact
