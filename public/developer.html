Display Amazon Products with Product Links

Amazon's own link builder generates HTML you can paste straight into WordPress — images, prices-as-text, and affiliate tracking included. No Creators API access needed, so it works while your account is still earning toward eligibility.

Show Me How Developer Notes

Step 1 — Get Your Product Links Code

Amazon retired its old JavaScript widgets in 2022. The current replacement is the Product Links tool in Associates Central, which outputs plain HTML you can embed anywhere.

Step 1.1

Open the Product Links tool

  1. Sign in to Amazon Associates Central (affiliate-program.amazon.com).
  2. In the top menu, go to Product Linking → Product Links.
Step 1.2

Find a product

  1. Search by product name, keyword, or paste an ASIN (e.g. B08N5WRWNW).
  2. Click the product you want to promote.
Step 1.3

Choose a format and copy the code

  1. Pick a format:
    • Text — a plain affiliate link.
    • Image — the product photo linked to Amazon.
    • Text and Image — the full box: photo + title + price + your affiliate tag.
  2. Click Get Link.
  3. Click Copy Code — the generated HTML is now on your clipboard.
Faster shortcut — SiteStripe: While signed in, open any product page on Amazon. The SiteStripe bar at the top has Text, Image, and Text and Image buttons that generate the same code instantly, without visiting Associates Central.
Important: the generated HTML contains your unique tag= tracking parameter. Never strip or alter it — that's how Amazon credits your sales.

Step 2 — Add It to WordPress

Choose the placement that fits your site. All four options work with the same copied code.

Page / Post Editor

Inside an article

In the block editor, click the + icon, search for Custom HTML, paste the code, and publish. Renders inline with your content.

Appearance → Widgets

Sidebar / footer widget

Add a Custom HTML widget to any widget area (sidebar, footer, homepage) and paste the code into it. Shows site-wide.

Theme Template

Directly in PHP

Developers: paste the HTML inside any theme file (e.g. single.php). Use a PHP snippet to conditionally render it per-post.

Plugin Shortcode

Plugin-native approach

Once your Creators API account is eligible, replace static code with the plugin's [amazon_box], [amazon_link] or [amazon_button] shortcodes for live prices and automatic updates.

Recommended path for new sites: use [amazon_link] and [amazon_button] shortcodes now — they render working affiliate links with zero API access. Add Product Links boxes for visual content today, then swap them for [amazon_box] when the Creators API unlocks.

Developer Notes

What Product Links are (and aren't) under the hood.

  • Static HTML, no JavaScript. The code is an anchor tag (and an <img> for image formats). No API keys, no credentials, no rate limits.
  • Works regardless of Creators API eligibility. Product Links only need your Associates account — not the 10-sales threshold. This is the fastest way to monetize while you qualify.
  • Not live-updating. A Product Link is a snapshot — price and availability only change when you regenerate it. For live data, use the plugin shortcodes with an eligible Creators API account.
  • Every link embeds your tracking tag. Keep tag=yourname-20 intact or the click won't be attributed to you.
  • Compliance is automatic-ish. Amazon requires a disclosure. The plugin's product cards add one automatically; if you paste raw HTML, add your own “As an Amazon Associate I earn from qualifying purchases.” line nearby.
