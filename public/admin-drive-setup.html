1
Create a Shared Drive in Google Drive

Shared Drives are required — service accounts cannot upload to personal "My Drive" folders.

1
Open Google Drive
Go to https://drive.google.com and sign in with your Google account.
2
Create a Shared Drive
In the left sidebar, click "Shared drives" → "+ New" → name it (e.g., WhoIsDesir Media — Client Files).
3
Create a folder for each client
Inside the Shared Drive, create a folder for each client (e.g., Start Social — World Cup Project). You can also create sub-folders like Photography, Video, etc.
4
Share the folder with the service account
Right-click the client folder → "Share" → add: widmedia-drive-upload@whoisdesir-media.iam.gserviceaccount.com → set permission to "Editor" → click "Send".
Critical: The service account MUST be added as an Editor (not Viewer). Without Editor access, uploads will fail with a 403 permission error.
2
Get the Folder ID

You need the Google Drive folder ID to link it in the admin portal.

1
Open the folder in Google Drive
Double-click the client folder to open it. Look at the URL in your browser.
2
Copy the Folder ID
The URL looks like:
https://drive.google.com/drive/folders/1aBcDeFgHiJkLmNoPqRsTuVwXyZ
The part after /folders/ is the Folder ID: 1aBcDeFgHiJkLmNoPqRsTuVwXyZ
3
Copy the full Shareable URL
Copy the entire URL from the address bar — you'll paste both the ID and URL in the admin portal.
3
Link the Folder to a Client in the Admin Portal

Now paste the folder details into the client's record.

1
Go to the client's detail page
In the admin dashboard, click "Clients" in the sidebar → click the client name.
2
Click "Edit Client"
On the Overview tab, click the "Edit Client" button at the bottom of the Client Details card.
3
Scroll to "Google Drive Media Folder"
Paste the Folder ID and Shareable Folder URL into the respective fields. Click "Save Changes".
Optional — Sub-folders: For organized delivery (Photography, Video, etc.), go to the client's "Folders" or "Media Gallery" tab and create named sub-folders with their own Drive folder IDs. Vendors can then pick the specific folder when uploading.
4
Verify the Setup
1
Check the client overview
Back on the client's Overview tab, the "Media Folder" card should now show ✓ Linked instead of "⚠ Not linked".
2
Test with a vendor
Ask a vendor to open a project, select the client's folder from the dropdown, and upload a test image. If it succeeds, the setup is working.
3
Test the client view
Log in as the client (or ask them to) → go to "Media Gallery" → they should see the folder and its files.
!
Troubleshooting
!
Vendor sees "Drive not configured" or 503 error
The Google Drive service account credentials aren't set in the Vercel environment. Check that GOOGLE_SERVICE_ACCOUNT_EMAIL and GOOGLE_PRIVATE_KEY are set in your Vercel project settings → Environment Variables.
!
Vendor sees 403 "Permission denied"
The service account doesn't have access to the folder. Go to the folder in Google Drive → "Share" → add widmedia-drive-upload@whoisdesir-media.iam.gserviceaccount.com as Editor.
!
"Service Accounts do not have storage quota"
The folder is in someone's My Drive, not a Shared Drive. Move the folder to a Shared Drive and re-share it with the service account.
!
Client's Media Gallery is empty
The client's googleDriveFolderId isn't set, or the folder has no files. Check the client's Overview tab and verify the Folder ID is correct.
